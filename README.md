<h1 align="center">Bit Clever Studio</h1>
<p align="center">A Windows workspace for creative references, projects and business.</p>
<p align="center"><a href="https://github.com/dottereldesign/Bit-Clever-Studio/releases/latest">Download for Windows</a></p>

## Finished

- **Design Inspo** — Collect, browse and organise visual inspiration in your own library.
- **App Components** — Build a reference library of interfaces, components and page patterns.

## Still in development

Everything below is **incomplete**. Some tools already work, but these sections are still being built.

| Section | Purpose |
| --- | --- |
| **Home** | Your workspace overview. |
| **Marketing** | Campaigns and content planning. |
| **Leads** | Enquiries, opportunities and follow-ups. |
| **Organisations** | Client relationships and records. |
| **Projects** | Project work, files and delivery. |
| **My Business** | Your own business setup and operations. |
| **General** | Saved links and reusable resources. |
| **Analytics** | Reports on your recorded activity. |
| **Research** | Research, sources and findings. |
| **Code** | Planned development workspace. |
